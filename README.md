
# ☕ Cafe Nova

A modern and elegant café website built with **React.js**, designed to showcase coffee varieties and a smooth interactive browsing experience.

The project focuses on creating a visually appealing café experience with **animations, page navigation, responsive design, and CSS-based interactions**.


##  🖥️ Preview

![Project Preview](./public/Preview%20Demo.png)




## ✨ Features

* ☕ Modern café-inspired UI
* 📱 Fully responsive design
* 🎨 Custom CSS styling and transformations
* ✨ Smooth animations using **Framer Motion**
* 🧭 Page navigation using **React Router**
* 📖 Coffee collection showcasing different varieties
* 🏠 Interactive home and about sections
* 📜 Dedicated pages for additional café information
* ⚡ Fast and component-based React architecture
* 🖱️ Interactive buttons, navigation, and UI elements

## 🛠️ Technologies Used

* **React.js** – Frontend library for building the user interface
* **React Router** – Client-side routing and page navigation
* **Framer Motion** – Animations and smooth UI transitions
* **HTML5** – Structure and semantic markup
* **CSS3** – Styling, layouts, animations, and transforms
* **JavaScript (ES6+)** – Application logic and interactivity
* **Vite** – Development and build tool

## 🎨 Design & Animations

Cafè Nova uses a combination of modern CSS and animation techniques to create a smooth café experience.

### Framer Motion

Used for:

* Page transitions
* Element entrance animations
* Smooth movement and scaling
* Interactive UI effects

### CSS Transforms

Used for:

* Hover effects
* Image scaling
* Card interactions

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Sanjugupta65/Cafe_Nova.git
```

### 2. Navigate to the Project

```bash
cd Cafe_Nova
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

The application will start on the local development server provided by Vite.
